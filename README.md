# 半撇自媒体定位助手

帮助个人和企业找到适合自己的自媒体账号方向。通过填写模板和真实经历、业务资料，梳理“服务谁、提供什么价值、为什么可信、怎样持续做”，给出定位候选和小规模验证方案。

支持新账号起步、老账号调整，也适合不以变现为目标的创作者。先展示模板与填写案例，允许自由回答、跳过和使用已有资料；收到资料后先给初步判断，必要时最多补问一轮、两个问题，避免无休止追问。

## 可以帮你做什么

- 找方向：结合个人经验、兴趣和投入条件，或企业产品、客户问题及交付证据，比较一至三个有依据的定位候选。
- 查问题：有历史内容和数据时，区分定位、选题、表达、分发和转化问题。
- 做验证：设计有限的内容测试，根据真实反馈调整方向；定位方案先作为待验证的假设。
- 接着用：需要时保存独立的账号定位文档，下次读取后继续，多个账号分别管理。

## 下载安装

[下载最新技能导入包](https://github.com/banpie/banpie-skill-self-media-positioning/releases/latest)

### 在 WorkBuddy 中测试

在技能页面选择“添加技能”→“上传技能”，选择版本下载页中的“导入包”压缩文件。这一入口见 [WorkBuddy 官方安装说明](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)。导入包只包含一个完整技能目录及许可文件，保留所有参考资料和模板。

安装并启用后，新开对话输入：

```text
请使用自媒体定位助手，帮我找到适合我的账号方向。
```

首次使用应先看到信息模板和匹配案例。你可以按模板填写、自由讲述，或直接说“先给方案”“跳过”。已有足够资料时，会直接进入分析。

包结构与相对引用已检查；WorkBuddy 中的实际导入和对话效果仍待测试反馈。

### 从仓库安装

也可以将下面这段话发给支持安装 Agent Skills 的客户端：

```text
请从这个项目安装 banpie-self-media-positioning，只安装这一个技能：
https://github.com/banpie/banpie-skill-self-media-positioning/tree/main/banpie-self-media-positioning
安装后检查技能和引用文件是否能正常读取，先不要开始定位。
```

个人／企业使用示例和完整能力说明见 [使用说明](banpie-self-media-positioning/README.md)。

## 源码与许可

这是供个人或企业独立安装使用的公开技能，不需要作者的私人知识库、履历、客户记录或登录状态。技能核心不依赖额外密钥和其他技能，联网与文件能力由宿主提供；无联网能力时仍可给出标明证据缺口的初步方案。

本仓库是独立分发入口，技能源码从半撇技能母仓库同步。版本见 [版本文件](VERSION)，采用 [MIT 许可](LICENSE)。
