# 半撇自媒体定位助手

《大课 AI定位与人设赛道精准匹配实战课》的配套练习助手，帮助个人和企业找到适合自己的自媒体账号方向。通过填写模板和真实经历、业务资料，梳理“服务谁、提供什么价值、为什么可信、怎样持续做”，给出定位候选和小规模验证方案。

支持新账号起步、企业定位、老账号调整和成熟账号转型，也适合不以变现为目标的创作者。首次先提供简短入门讲解与流程说明，再展示模板与填写案例，允许自由回答、跳过和使用已有资料；资料不足最多补问一轮、两个问题；足够则先按模板回显全部已知信息，用户核对并同意生成后才给定位，避免无休止追问。

## 与指定课程逐章对应

以圈子发布版视频及逐字稿为依据，详见 [课程章节与练习对照](banpie-self-media-positioning/references/course-companion.md)。除骨架与血肉外，保留兴趣强度与投入时间矩阵、细分法则、反需求法、领域＋身份＋标签公式，以及名称组合筛选查重、头像生成提示词、简介结构。已看过课直接承接练习，尚未看过也可边做边学。

## 与半撇定位课程共用一套方法

**简历＋个人说明书＋运营条件 → 黄金三角 → 外部需求验证 → 五项定位骨架＋三项人设血肉 → 比较选择 → 账号呈现和小规模测试。**

五项骨架沿用“领域定位、用户定位、内容定位、变现定位、平台定位”；三项血肉沿用“职业标签、技能标签、情感标签”。模板完整保留课程信息维度，未知或不愿提供可以留空；企业在同一维度下映射团队与品牌，成熟账号标记保留与调整项。

[统一提示词：用于 Agent 配置或普通对话](prompts/自媒体定位统一提示词.md) 由 Skill 正文自动导出，包含完整流程、模板和方法，不另行维护一份简化逻辑。课程配套提示词采用相同导出。线上已安装技能及旧 Agent 的配置需要各自更新，本地拉取不会自动替换它们。

## 按你的经验与场景辅导

新手先用短说明理解定位是什么、怎么完成和会得到什么，再边做边理解。有经验的人缩短讲解，明确要求直接分析时可以跳过介绍，企业和成熟账号不会被要求重做新手问卷。账号主体、发展阶段和本次问题交叉判断：企业也可能刚起步，大 V 在陌生领域也需要重新验证。

- 无账号：从真实经历和可投入条件提出探索方向。
- 企业：连接业务目标、客户问题、交付证据和团队内容资源。
- 已有账号：先区分定位、表达、分发与业务承接问题。
- 成熟账号：保留已有受众与资产，比较升级或转型的路径与代价。

[查看从填写到定位的完整示范](banpie-self-media-positioning/references/worked-example.md)。

## 可以帮你做什么

- 找方向：结合个人经验、兴趣和投入条件，或企业产品、客户问题及交付证据，比较一至三个有依据的定位候选。
- 查问题：有历史内容和数据时，区分定位、选题、表达、分发和转化问题。
- 做验证：设计有限的内容测试，根据真实反馈调整方向；定位方案先作为待验证的假设。
- 接着用：需要时保存独立的账号定位文档，下次读取后继续，多个账号分别管理。

## 下载安装

[下载最新技能导入包](https://github.com/banpie/banpie-skill-self-media-positioning/releases/latest)

### 在 WorkBuddy 中测试

在技能页面选择“添加技能”→“上传技能”，选择版本下载页中的“导入包”压缩文件。这一入口见 [WorkBuddy 官方安装说明](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Function-Description/Skills-Market)。导入包只包含一个完整技能目录及许可文件，保留所有参考资料和模板。

安装并启用后，新开对话输入：

```text
请使用自媒体定位助手，帮我找到适合我的账号方向。
```

首次先看定位解释、流程和本轮终点，随后是相关模板和匹配案例。你可以按模板填写或自由讲述；“这题跳过”只跳当前题，“先给方案”“不问了”结束收集。首条消息已附完整资料时，简短介绍后代填完整模板，等待核对与生成确认；历史记忆须标明来源，不能自动代替确认。

包结构与相对引用已检查；WorkBuddy 中的实际导入和对话效果仍待测试反馈。

### 在线 ChatGPT

安装后从技能详情点击“在聊天中试用”，或新对话用 `@` 选择技能。0.4.1 首次显示版本和阶段，资料不足先收集；资料齐全先得到完整模板资料表，等你核对并确认生成后再分析。若回复说没有实际启动技能，应先解决加载，不能把通用建议当作技能结果。详细步骤见 [加载排查](banpie-self-media-positioning/README.md#首次流程与加载排查)。

本地 Git 拉取不会更新在线副本，在线版需单独更新。阶段规则仍由模型执行，不等于程序强制控制。

## 源码与许可

这是供个人或企业独立安装使用的公开技能，不需要作者的私人知识库、履历、客户记录或登录状态。技能核心不依赖额外密钥和其他技能，联网与文件能力由宿主提供；无联网能力时仍可给出标明证据缺口的初步方案。

本仓库是独立分发入口，技能源码从半撇技能母仓库同步。版本见 [版本文件](VERSION)，采用 [MIT 许可](LICENSE)。
