# 半撇自媒体定位助手

为个人或企业寻找、验证与调整账号定位，同时支持新账号和老账号。模板与案例优先，接受自由讲述；资料提交后先给初步判断，必要时最多再补问一轮、两个问题。

完整的安装方法、个人／企业使用示例及能力说明见 [使用说明](banpie-self-media-positioning/README.md)。

## 安装入口

将下面这段话发给支持 Agent Skills 的客户端：

```text
请从这个项目安装 banpie-self-media-positioning，只安装这一个技能：
https://github.com/banpie/banpie-skill-self-media-positioning/tree/main/banpie-self-media-positioning
安装后检查技能和引用文件是否能正常读取，先不要开始定位。
```

安装后新开对话，说“使用自媒体定位助手帮我找方向”。可以随时说“先给方案”或“跳过”，不必填满所有信息。

## 源码与许可

本仓库是独立安装分发入口，技能源码从半撇技能母仓库同步；不携带私人知识库、履历、客户记录或登录状态。技能核心不依赖额外密钥和其他技能，联网与文件能力由宿主提供。通用格式不等于已逐一实测所有客户端。
