# 半撇自媒体定位助手

这是一个给自媒体创作者使用的 Agent Skill。它会先读取真实经历和账号资料，再生成三套可验证的定位假设；老账号还可以结合内容、用户和转化数据诊断定位问题。

它不会替你拍脑袋宣布“天命赛道”，也不会承诺涨粉或变现。最终定位仍然需要你选择，并用真实内容测试。

## 安装

在 Codex、WorkBuddy 或其他支持 Agent Skills 的客户端里，把下面这段话发给 Agent：

```text
请从这个 GitHub 项目安装 banpie-self-media-positioning，只安装这一个 Skill：
https://github.com/banpie/banpie-skill-self-media-positioning/tree/main/banpie-self-media-positioning

安装完成后，告诉我能不能正常使用；如果还缺什么，请用简单的话告诉我。先不要开始做定位。
```

## 使用

安装后，新开一个对话，输入：

```text
请使用 banpie-self-media-positioning，读取当前项目里的资料，帮我完成自媒体定位。先判断我是新账号还是老账号，不要跳过提问，也不要直接替我决定最终方案。
```

## 它会做什么

- 新账号：盘点擅长、长期兴趣和独特资源，结合市场需求给出三套定位假设。
- 老账号：结合内容表现、粉丝画像和转化数据诊断定位问题。
- 每套方案：包含领域、用户、内容、平台、变现五项骨架，以及真实身份、差异化经历和价值观三项人设血肉。
- 最终结果：生成定位卡、内容支柱、明确不做什么，以及首轮低成本测试计划。
