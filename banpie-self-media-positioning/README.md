# 半撇自媒体定位助手

帮助个人和企业找账号方向，也能根据已有内容、用户反馈和业务结果调整老账号定位。需要时先用短说明理解定位，再给信息模板和一个填写案例，接受自由讲述或已有资料；收到后先给初步判断，必要时最多再补问一轮、两个问题。

不会填模板时可说“带我聊”，改为一次一个问题，默认三问后给初步判断，首次最多五问。说“这题跳过”只跳当前题；说“先给方案”“不问了”即可结束信息收集。未知项不必填满，提问额度不会因切换路径自动重置。

## 按你的情况开始

不懂定位时，先用一句定义和案例解释“定位是什么、如何完成、会得到什么”，随后边做边理解；不用上完课或通过测验。有经验或要求直接分析时跳过基础讲解。无账号不等于零经验，企业也可能从零起步。

| 当前场景 | 重点 |
| --- | --- |
| 完全没有账号 | 从具体经历与可投入条件找到能尝试的方向，不要求历史数据 |
| 少量试发 | 利用已有作品给有限判断，不凭一条内容定成败 |
| 企业、创始人或团队 | 对齐业务目标、客户问题、内容资源与账号角色 |
| 已有账号遇到瓶颈 | 先找值得保留的部分，再区分定位、内容与承接问题 |
| 成熟账号或大 V 转型 | 评估已有受众与资产，比较相邻栏目、渐进调整或独立探索的代价 |

这些场景可以交叉，按本次问题选择流程，不用先填写分类问卷。详见 [场景适配](references/scenarios.md)。

## 安装

在支持 Agent Skills 的客户端中，把下面这段话发给智能体：

```text
请从这个项目安装 banpie-self-media-positioning，只安装这一个技能：
https://github.com/banpie/banpie-skill-self-media-positioning/tree/main/banpie-self-media-positioning
安装后检查技能入口及其引用文件能否读取，告诉我结果，先不要开始定位。
```

也可以将发布包内的 `banpie-self-media-positioning` 完整目录放入客户端支持的技能目录。具体导入位置、自动发现和重载方式以该客户端为准；安装后新开对话。通用格式不代表已逐一实测所有客户端。

核心不需要额外密钥、账号登录或其他技能。联网研究和保存文件取决于客户端能力；没有网络时会明确标注未核验部分，没有文件能力时会提供可复制的定位文档与续聊摘要。

## 开始使用

```text
使用 banpie-self-media-positioning 帮我找自媒体定位。先利用我已经提供的资料；如果还没有资料，给我简短模板和一个参考案例。我回复后，先给初步判断，不要一直追问。
```

企业可直接说：

```text
使用 banpie-self-media-positioning 帮我们企业确定账号方向。先给适合企业的填写模板和案例；我们不一定要做老板个人号，请结合业务目标和团队资源判断。
```

已有资料时，可以直接发个人介绍、产品说明、作品、用户提问或账号数据，并指定允许读取的文件。没有资料也可以只讲自己的情况，不要求先写出目标受众、商业模式或完整定位。

[查看个人与企业填写模板及完整案例](references/intake.md)，或 [从填写到定位的完整示范](references/worked-example.md)。案例均为虚构，只示范具体程度，不是需要照着包装的履历。

## 你会得到什么

- 先给简短判断：首选、事实依据、代价或未知、第一步；需要时比较最多三套候选，并说明什么证据会改变推荐。
- 选定后的定位卡：服务谁、提供什么内容、为什么可信、如何持续做，以及目标与回报路径。
- 内容支柱、示例选题和符合时间精力的有限测试。
- 老账号的证据诊断：区分定位、内容表达、分发和业务承接，不凭一条低播放建议换方向。

个人表达、职业机会、品牌信任、招聘、客户教育、获客或收入都可以作为目标，不强制变现。

## 深入、保存与复盘

可以继续说“深入研究这两个方向”“我选第二个，展开定位卡”“把目前结果保存下来”或“根据这些反馈更新定位”。

进入深度研究后，有联网能力就检查真实需求、同类内容和替代方案，并记录来源与证据缺口。用户选定只代表采用一个待验证假设，不代表市场验证成功，也不承诺涨粉或收入。

有文件能力时默认保存为 `自媒体定位.md`，优先更新已有同一账号文档；多账号分开保存。新会话提供该文档即可继续，避免重新填写。

本技能不自动发布内容、修改公开账号、联系客户或购买数据。账号起名、头像与简介属于定位确定后的可选工作。

## 方法与版本

本版融合半撇历史定位智能体的模板、案例和流程，以及黄金三角、定位骨架、需求核验和内容测试方法。具体取舍见 [方法来源与取舍](references/method-origins.md)。

版本：0.3.0。核心流程采用通用技能格式，客户端能力差异以实际检查结果为准。
