# 老账号诊断

老账号先看已有证据，由助手映射到统一信息模板并等待核对，不要求用户重新填写。读取用户可提供的内容、受众和目标结果三类资料，记录时间窗口、平台、样本数量和缺口；没有完整三类数据仍可以给粗诊断，但降低结论强度。

## 资料怎么用

- 内容：主题、形式、发布时间、曝光／播放／阅读、点击、停留／完播、互动、关注。尽量包括普通表现与低表现内容，不能只看爆款。
- 受众：实际评论、反复提问、地区和与业务有关的角色信息；后台画像只能说明可见部分。
- 目标结果：有效咨询、资料使用、合作机会、成交或个人表达反馈，跟随用户目标。未记录的转化不记为零。

数据可来自文本、现有表格、截图或用户概括；不能读取图片或表格时坦诚说明，允许用户只提供关键内容，不要求为完成诊断重做整个数据系统。

## 区分问题层次

| 观察 | 可能的问题 | 进一步核对 |
| --- | --- | --- |
| 观看者与希望服务的人不同 | 用户或内容定位不匹配 | 评论身份、地区、实际咨询需求 |
| 相同受众相关内容，表现波动大 | 选题、标题封面、表达或分发 | 内容具体差异、曝光与停留；不能直接换赛道 |
| 有匹配受众、咨询少 | 内容价值、行动入口或需求成熟度 | 内容是否回答决策问题、咨询入口是否清楚 |
| 有有效咨询、成交少 | 产品、价格、履约或成交周期 | 客户反馈与业务阶段；不能全归因于定位 |
| 内容主题多，但同一群人持续受益 | 可能是合理的多主题结构 | 用户问题是否连贯、栏目能否解释 |
| 曝光少或样本很小 | 暂时不足以判断 | 先改善可见性或继续有限测试 |

上述是诊断假设，必须与本次证据对应，不能按表格自动断言因果。

## 输出

完成资料核对并获准分析后，先给值得保留的资产，再给最可能的问题及证据、其他解释、不能下结论的部分。每个建议说明保持定位、调整内容／承接，还是需要比较新的定位候选。没有足够证据时优先做局部测试，不把老账号一律推倒重来。

建议更换方向时说明旧受众、已有素材、业务承接和团队产能的影响；先让用户选择再更新当前采用的定位。回访依照入口链接的研究与验证参考，不因“诊断”开启无限资料收集。
